# AI image and video assets

Follow [references/before-you-start.md](references/before-you-start.md) to choose Content OS or standalone mode. Read the creator's brand and the matching video-manifest profile if available. Establish the visual purpose, subject, style, aspect ratio, duration for video, and whether a supplied reference may be used. Preserve the user's intended look and avoid inventing specific brand details.

Discover the host's available image or video generation tools, or a connected provider the user already has. Use the provider's actual capabilities and report its outputs honestly: an image generator alone does not produce video. Some services require credentials or usage charges. Do not ask the user to paste credentials into chat. If the requested media type has no available provider, produce a useful generation brief and identify what is missing rather than claiming to have generated an asset.

Use the user's provided references only for the requested purpose. Generate or edit the asset, inspect what was returned when the host allows it, and retain the generation prompt and relevant source/usage information next to the asset if files can be saved. For a Content OS workflow, store or attach an asset there only through a supported operation when requested; otherwise report the local file or provider result. In standalone mode use the relevant local idea or project folder. Do not automatically publish, replace existing files or add the asset to an editor unless requested.
