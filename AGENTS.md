# ContentAgent

Content-creation skills for YouTube and Instagram creators, working on the user's Content OS data through the Content OS MCP server.

Before running any skill, follow [`knowledge/before-you-start.md`](knowledge/before-you-start.md). Before reading or writing anything in Content OS, read [`knowledge/content-os.md`](knowledge/content-os.md). It defines the long- and short-form boards, what each status means and who may move ideas, what each idea field holds, and the HTML the app expects.

Each skill's instructions are in `skills/<name>/SKILL.md`. When the user asks for one of them, read that file and follow it.
